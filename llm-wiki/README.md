# 읽은 것이 사라지지 않는 서재

**법률가를 위한 LLM 위키 자습서 — 혼자서 처음부터 끝까지** · 권보원 엮음 · 2.0판(2026. 10. 13.)

- [화면본(HTML)](https://bowonkwon.github.io/AI-Assisted-Handbooks/llm-wiki/)
- [인쇄본(PDF, 98쪽)](llm-wiki-v2.0.pdf)

GitHub에서 `index.html` 을 누르면 책 대신 코드가 보이거나 파일이 커서 표시되지 않습니다. 책은 위 화면본 링크로 여십시오.

Andrej Karpathy가 제안한 「LLM 위키」 — 읽은 자료를 AI 에이전트가 요약·연결해 내 컴퓨터의 마크다운 폴더에 쌓아 가는 방식 — 를 법률가가 혼자서 만들고 석 달 동안 운영할 수 있게 쓴 자습서입니다. 2026년 9월 2일 사법연수원 「2026년 AI 리터러시 슈퍼위크」의 고급 실습 과정 「상용 인공지능(AI) 활용 실습 세미나 Ⅲ(고급)」 중 「에이전틱 AI 및 바이브코딩 활용례 시연」 강의 자료집에서 출발해, 강의를 듣지 않은 독자도 설치부터 따라올 수 있도록 다시 썼습니다. 본문은 Claude Code 기준이고, 같은 방식을 다른 에이전트로 옮기는 법도 적었습니다.

되는 것과 안 되는 것을 같은 무게로 적었습니다. 이 방식에 대한 비판을 한 장(제19장)에 통째로 실었고, 무엇을 넣지 말아야 하는지와 데이터가 어디로 가는지(제18장), AI가 만든 인용을 다시 확인하는 습관(제20장)을 실습보다 앞에 둘 만큼 무겁게 다룹니다. **실습은 공개된 자료로만 하십시오.**

| 제2부 개념 | LLM 위키란 무엇인가 · 「AI에 파일 올리는 것」과의 차이 · 네 개의 층 · 이론적 배경 |
