# 생각하고, 행동하고, 고쳐 쓰는 기계

**ReAct에서 LLM Wiki까지, Agentic AI 논문 읽기** · 일요일은 AI · 에이전트 스터디 · 권보원 엮음 · 1.0판(2026. 10. 5.)

- [인쇄본(PDF, 408쪽)](agentic-ai-reading-v1.0.pdf)

## 어떤 책인가

「일요일은 AI」 스터디가 매주 한 시간씩 Agentic AI 논문을 읽으려고 엮은 자습서입니다. 확률·통계·선형대수와 프로그래밍 기초는 안다고 보고 썼습니다. 자연어처리와 강화학습이 처음이면 0장(사전 자습)부터 읽으면 됩니다. 다른 모임에서 같은 방식으로 스터디를 하거나 혼자 읽어도 됩니다.

회차마다 틀이 같습니다. 발제 가이드(50분 배분), 직관 잡기, 본론, 「통계의 눈으로 다시 읽기」(논문에 인쇄된 숫자로 해 보는 재분석, 접이식 풀이), 논문이 스스로 밝힌 한계, 곁가지 논문, 두 서베이 속 위치, 자주 하는 오해, 토론 질문, 영상과 후속 공부 순서입니다. 전체 20회, 필수만 15회, 최소 13회로 운용할 수 있습니다.

## 차례

| | 주제 |
|---|---|
| 사용법 · 0장 | 이 책의 사용법 / 사전 자습: 언어모형·토큰·문맥 내 학습·강화학습 용어 |
| 1~3회 | 에이전트란 무엇인가 / 에이전트의 머리(Agentic Reasoning 서베이) / 몸과 울타리(하네스 서베이) |
| 4~6회 | Chain-of-Thought / Tree of Thoughts / ReAct |
| 7~10회 | 도구 사용과 표준 규약 / RAG / Lost in the Middle과 컨텍스트 엔지니어링 / Self-RAG |
| 11~14회 | RARR와 Reflexion / MemGPT / MetaGPT / SWE-agent |
| 15~16회 | 간접 프롬프트 인젝션 / 정렬 |
| 17~19회 | 에이전트 평가의 지도 / 평가 결과를 통계학의 눈으로 / HarnessFix |
| 20회 | 종합: LLM Wiki, 지식을 컴파일하는 에이전트 |
| 부록 | 기호표, 용어 통일표, 서지·링크 목록, 영상 목록(56편) |

다루는 원문은 논문·보고서 42편, 블로그·사양 문서·강의 페이지·gist 19편입니다.

## 어떻게 만들고 검증했나

엮은이가 Claude Code와 함께 만들었습니다.

1. **서지 확인.** 스터디에서 처음 제안된 논문 목록을 arXiv 메타데이터와 학회 공식 목록(NeurIPS·ICLR proceedings, ACL Anthology, TMLR, Crossref DOI)으로 대조했습니다. 연도·게재처·제목이 틀린 일곱 건을 고쳤습니다.
2. **초고.** 장마다 설계와 원문 PDF만 보고 썼습니다. 절·그림·표 번호, 수치, 인용문은 원문에서 확인한 것만 적었습니다.
3. **독립 검증.** 초고를 쓰지 않은 검토자에게 초고와 원문만 주고 문장 단위로 대조하게 했습니다. 21개 장을 합쳐 약 3,500건을 대조했고, 틀린 것으로 판정된 6건과 부분적으로 맞는 것으로 판정된 약 215건을 모두 원문으로 다시 확인해 고쳤습니다. 「통계의 눈으로」 절의 계산은 검증 때 다시 돌렸고, 어긋난 5건을 고쳤습니다.
4. **공개판 검토.** 공개에 앞서 표현을 다시 검토해 79곳을 고쳤습니다. 공개 직전에 새로 쓴 문단은 원자료와 그 문단만 받은 검토자가 따로 확인했습니다.
5. **빌드 점검.** 바깥 링크 245개(고유 주소 기준)를 모두 열어 확인했습니다. 화면본과 인쇄본의 링크 수가 일치하는지, 빌드 과정에서 사라진 문단이 없는지도 셌습니다.

## 읽을 때 알아 둘 것

- **원문을 대신하지 않습니다.** 발제와 인용은 원문으로 하고, 수치는 원문 표를 다시 보십시오.
- **수치의 시점.** 논문의 성능 수치는 그 시점의 모델(PaLM-540B, GPT-3, GPT-4 등)에서 나온 것입니다.
- **심사 상태.** 2026년 자료 여럿은 preprint입니다. 2회의 기준인 Agentic Reasoning 서베이는 2026. 10. 5. 현재 TMLR 심사 중입니다(액션 에디터 「Accept as is」, OpenReview 「Decision pending」). 정식 판이 나오면 절·표 번호를 다시 대조합니다.
- **기업 문서.** Anthropic·OpenAI·Manus·Chroma의 글은 자사 제품을 만든 경험에서 나온 처방입니다. 일반화된 실증으로 읽지 않습니다.
- **「통계의 눈으로 다시 읽기」는 논문 밖의 재분석입니다.** 논문의 결론을 뒤집으려는 것이 아닙니다.
- **보안 실습.** 프롬프트 인젝션 실습은 자기 소유 환경이나 공개 평가 환경에서만 하십시오.
- **링크.** 2026년 10월 초에 확인했습니다. 블로그와 영상은 사라지거나 주소가 바뀔 수 있습니다.
