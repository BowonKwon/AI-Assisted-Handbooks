# Notebooks — *Blockchain for Lawyers: A Reading Through Technology and Economics* (English edition)

These 21 notebooks carry over the Python code cells of the text, chapter by chapter, unchanged (Part 0: NB00 · Part 1: NB04–NB12 · Part 2: NB13–NB17 · Part 3: NB19–NB25 · Part 6: NB29). The outputs are the results of the editor's runs in Python 3.13.17, and the "Output" blocks in the text came from the same runs. "NB09-2" in the text is the second code cell of notebook NB09. Comments and printed labels are in English; the numbers are the same as in the Korean edition's notebooks.

- **External packages.** Only NB25 uses one, `numpy` 2.5.4 (the reason is in `requirements.txt`). The rest use the standard library alone. There is no installation cell, and no external API is called.
- **Bundled data.** NB12 reads `data/genesis_header.hex` and `data/genesis_block.hex`, NB20-3 reads `data/hashrate_2026-10-25.json`, and NB29-2 reads `data/exposed_output_types_2026-10-25.json`. If a file is missing, a constant with the same value is used instead, so the notebooks run on Colab without the files. NB25 uses **synthetic data only** (fixed seed, no real price data; see Chapter 25). The `data/` folder is shared with the Korean edition.
- **Not for real use.** All the code is a toy for study. Do not use it with real assets, real private keys or real transactions.
