Running time differs from machine to machine and is not shown — the number of tries does not depend on the hardware.

What this miner does not show

  • Running time. The same 24,542 tries take anywhere from a few milliseconds to a few seconds depending on the machine. To state a time you would also have to state the measurement conditions (CPU, implementation, other work running at the same time), and so this widget counts only tries.
  • Bitcoin's actual condition is not "the first k bits are 0" but "hash ≤ the target that nBits points to" (Chapter 8, Section 3). The k-bit condition is the special case where the target is a power of 2.
  • When the 4-byte nonce runs out, a real miner changes the time or the coinbase and goes around again. Here k ≤ 20, so that does not happen.
  • The spread is not a defect; it is the nature of a lottery. And that spread is what gives the attacker an opening in Chapter 9.
