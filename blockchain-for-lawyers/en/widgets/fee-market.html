Chapter 21 · The fee market

A toll set by formula

The base fee is a function only of the parent block's gas used and its target (limit ÷ 2). If a block is full, the next block's base fee goes up by 1/8; if it is empty, it goes down by 1/8; if it equals the target, it stays where it is. Only the gas used per block moves, and you watch the path that results. The base fee is wei per gas set by the protocol, not market price data.

What this figure does not show

  • The tip the user specifies (priority fee), the fee cap, and burning. The base fee share is burned and the tip goes to the producer ((6) to (8) in the table in Chapter 21, Section 3).
  • The gas limit is not a protocol constant. It is a value that producers move block by block within ±1/1024 of the parent's, and the observed value on the reference date, 60,000,000, is in Appendix A-10.
  • The blob fee market (EIP-4844) is the same principle with a different resource and a different update formula (fake_exponential) — Chapter 21, Section 5, NB21-3.
  • The comparison of incentives with the first-price auction (whether guesses about "what others will bid" enter the payment) is in NB21-2.
